====================
How to run our code:
====================

1: Run the reversi_server.py script from the terminal to start the game server host
    cmd: python reversi_server.py

2: Start a second terminal and run one of the player scripts (Deep or Greedy implemented) 
    cmd: python deep_player.py

3: Start a third terminal and run one of the player scripts (Deep or Greedy implemented)
    cmd: python greedy_player.py 

Dev Notes: 
    - I would definately try multiple runs, with:
            - deep vs deep (for a pretty decent gameplay)
            - deep vs greedy      (for absolute annihilation)
